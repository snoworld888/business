**四个踩坑（都已写进脚本注释与 skill）**：

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| **`about:blank` 访问 `localStorage` 抛 SecurityError** | 跳过登录页时（`TC_ONLY=...`）必现 | 先 `Page.navigate` 到站点再注入 |
| **antd `Segmented` 不是 `Tabs`** | 点「分析引擎状态」报「候选节点 0 个」 | 选择器同时覆盖 `.ant-tabs-tab-btn` / `.ant-segmented-item-label`；**并输出候选节点数**，否则分不清「选择器错」还是「没渲染」 |
| **`innerText` 依赖布局** | 元素被隐藏时返回空串 ⇒「明明有节点却匹配不上」 | 判文本改用 `textContent` |
| **截到空态图** | 需求探针默认词命中 0 条、赛道评分未选卡片 | 支持预置 `sessionStorage` 与动态 hash（预选分数最高那张卡） |

### 交付三：★ 截图时肉眼发现真实缺陷 F-03（并修掉）

**现象**：赛道评分右侧「风险预警」是 **4 个有图标、没有文字的黄色空卡**。

**根因**：`risk_alerts` 有两条产出路径 —— 规则引擎给结构化条目
（`{dimension, level, title, detail}`），**真实大模型给叙事性字符串数组**
（「交付能力瓶颈：50-200 人规模难以支撑…」）。而**两个消费方各自假设了形态**：

| 消费方 | 症状 |
| --- | --- |
| 界面 `Scorecard.tsx` | `r.title`/`r.detail` 全是 `undefined` ⇒ 空卡 |
| 报告 `report.py` | `dicts_only()` 把字符串**整段过滤** ⇒ 风险段恒为「暂无触发阈值的风险项」 |

**两个症状完全不同、同一个根因**。实测证据：历史报告 V1.3/V1.4/V1.5 的风险段全是「暂无」，
而同一张卡片的 `risk_alerts` 里有 4 条模型识别出的风险 —— **报告一直在静默丢内容**。

**修法（两端，遵循约定 50）**：新增 `agents/base.py::normalize_risk_alerts()`；
决策 Agent **合并「阈值预警（可追溯）+ 模型叙事风险（有业务语境）」**
（此前模型路径会把确定性阈值预警整个顶掉，属能力损失）；`report.py` 改用同一函数
（顺带让旧数据也能进报告，免去数据迁移）；前端 `widgets.tsx::riskItem()` 兜底；
`types.ts` 如实放宽为 `RiskAlertLike = RiskAlert | string`。

**验证（旧数据也要验，不能只验新数据）**：
- 旧字符串数据卡片 ⇒ 页面文本 1390 → **1634 字**，四张卡显示「风险提示 + 完整文案」，无控制台报错
- 旧数据重新生成报告 ⇒ 风险段由「暂无」变为 **4 条**
- 真实模型重跑分析 ⇒ `risk_alerts` 为结构化条目（含 dimension/level/title/detail）
