## 三、为什么这么设计（不是"没做"，是"故意的"）

技术文档 §5.5 要求「多模型路由 + 成本控制 + 支持私有化」。据此把 LLM 调用抽象成
`LLMService.complete()`，每个 Agent 同时提供两份实现：

| 实现 | 作用 | 何时生效 |
| --- | --- | --- |
| `rule()` | 确定性规则/算法实现 | `LLM_PROVIDER=rule` 或远端不可用时的兜底 |
| `build_prompt()` | Prompt 模板，驱动真实大模型 | `LLM_PROVIDER=openai\|ollama` 且远端就绪 |

好处：

1. **零配置即可端到端跑通** —— 没有 API Key、没有 GPU、没有外网也能演示完整业务闭环。
2. **测试可断言、可回归** —— 规则实现输出确定，246 个单测才有意义；换成 LLM 后输出不确定，测试无法成立。
3. **换模型不改业务** —— 切换 provider 后，`rule()` 自动降级为**校验基线**（用来对照大模型输出是否跑偏），而不是被删掉。
4. **远端故障自动兜底** —— 大模型超时/额度耗尽时自动回退规则引擎，并在 `_meta` 里记录 `error`，业务不中断。

## 六、嵌入模型（RAG 的向量化通道）

RAG 有**两条独立的模型通道**，此前容易混为一谈：

| 通道 | 服务 | 默认后端 | 是否会加载本地模型 |
| --- | --- | --- | --- |
| **生成**（对话/推理） | `app/services/llm.py` → `llm.complete()` | `rule`（规则引擎） | 否 |
| **嵌入**（向量化） | `app/services/embeddings.py` → `embed()` | **`local`（确定性哈希）** | 否（零依赖） |

**默认状态：两条通道都不加载本地模型**，所以运行中的系统显存占用为 0。

### 6.1 三个后端

| `EMBEDDING_BACKEND` | 实现 | 维度 | 依赖 |
| --- | --- | --- | --- |
| `local`（默认） | `LocalHashEmbedding` — 字符 1/2/3-gram 哈希 + L2 归一化 | 1536 | 无（纯标准库） |
| `ollama` | `OllamaEmbedding` — 调用本机 Ollama | **1024**（bge-m3） | 需 `bge-m3` 已 pull |
| `openai` | `OpenAICompatibleEmbedding` — OpenAI 兼容接口 | 1536 | 需 `LLM_API_KEY` |

### 6.2 ⚠️ 切到 Ollama 时的三处坑（本次已修）

| # | 坑 | 现象 | 修复 |
| --- | --- | --- | --- |
| 1 | **模型名体系不同** | 用 `EMBEDDING_MODEL=BAAI/bge-m3`（HuggingFace 名）调 Ollama → **`model "BAAI/bge-m3" not found`** | 新增 `EMBEDDING_OLLAMA_MODEL=bge-m3`，ollama 分支专用 |
| 2 | **端点不同** | 只写 `/api/embeddings`（旧端点，入参 `prompt`），新版 Ollama 已弃用 | 改为 `/api/embed` + `input` 优先，**旧端点自动兜底**，兼容各版本 |
| 3 | **维度不同** | bge-m3 是 **1024** 维，而 `EMBEDDING_DIM` 默认 **1536**（那是 OpenAI 的）→ 向量与 Milvus schema / 既有入库向量不一致 | 按模型名预置正确维度，并在每次调用后用真实返回长度校正 |

**另加一层保护**：`embed()` 在**调用期**远端失败时降级为 `local` 并打 WARNING，
不再让嵌入不可用导致整条 RAG / 画像链路中断（local 自身异常仍会抛出，避免掩盖真实缺陷）。

### 6.3 切换方式

```bash
# backend/.env
EMBEDDING_BACKEND=ollama
EMBEDDING_OLLAMA_MODEL=bge-m3     # Ollama 仓库名，无组织前缀
```

> ⚠️ 切换嵌入后端会让**既有向量失效**（1536 维 ↔ 1024 维不可比），需重建索引：
> `POST /api/v1/signals/reindex`
>
> ⚠️ 同时需保证 `OLLAMA_MAX_LOADED_MODELS ≥ 2`，否则嵌入模型与对话模型会互相驱逐
> （详见 `docs/显存优化与云模型评估.md` §一之二）。

### 6.4 自查

`GET /api/v1/health` 与 `GET /api/v1/admin/model-config` 均**如实上报实际生效**的后端与维度
（而非配置文件里的期望值），并同时给出 `configured` 对照口径 —— 避免"配置写 A、实际跑 B"这类误判。

```json
"embedding": {
  "backend": "LocalHashEmbedding",
  "model": null,
  "dim": 1536,
  "configured_dim": 1536
}
```
