AI设计
是的，赛道罗盘 TrackCompass 从产品设计、技术架构到原型交互，都明确设计了大模型和智能体（Agent），而且它们不是点缀，而是整个产品的核心引擎。
下面把设计中涉及大模型和智能体的部分梳理清楚。

一、大模型设计
1. 模型选型与路由
技术文档中设计了多模型路由策略，按任务复杂度调用不同模型：
任务类型	模型示例	用途
简单任务	Qwen2.5-7B / GPT-3.5	分类、抽取、摘要
复杂分析	GPT-4o / Claude 3.5	趋势研判、竞争分析、报告生成
私有化部署	Qwen2.5-72B	数据敏感场景，本地推理
同时设计了缓存机制：相同 Query 结果缓存 24 小时，控制成本。
2. RAG 检索增强生成
认知层设计了完整的 RAG 流程：

Query → Embedding → Milvus 检索 → Top-K 文档 → Rerank → 
  → Prompt 组装 → LLM 生成 → 引用来源 → 输出

●使用 BGE-M3 / text-embedding-3-large 做向量化。
●混合检索：向量检索 + BM25 关键词检索，融合排序。
●每个结论附带 source_id，前端可下钻到原始证据。
3. 大模型在功能中的应用
功能模块	大模型作用
趋势雷达	分析政策、论文、专利、新闻，识别技术方向
需求探针	聚类社媒/评论痛点，判断需求强度与付费意愿
市场测算	辅助 TAM/SAM/SOM 测算与逻辑推理
竞争情报	识别竞品、大厂威胁、供应链卡点
技术评估	辅助 TRL/CRL 等六维评分
决策报告	自动生成立项报告/投资备忘录草稿
监控预警	分析信号变化，生成预警与复盘建议
4. 私有化与合规
●支持本地部署 Qwen2.5-72B，满足数据不出域。
●企业数据本地化，LLM 可配置为云端 API 或私有化模型。

二、智能体（Agent）设计
产品设计了七个 AI Agent，覆盖从信号扫描到决策复盘的全流程。
七 Agent 及职责
Agent	职责	输入	输出
趋势侦察 Agent	每日扫描 PESTEL、技术拐点、政策红利	政策、论文、专利、新闻	趋势列表、顺风/逆风
需求挖掘 Agent	聚类社媒/评论/招标/招聘中的痛点	社媒、评论、招标、招聘	痛点聚类、需求强度
市场测算 Agent	自下而上+自上而下测算 TAM/SAM/SOM	行业数据、财报、融资	市场规模测算
竞争情报 Agent	竞品动态、大厂威胁、替代方案	竞品、专利、招聘	竞争格局、威胁评分
技术评估 Agent	TRL/CRL/BRL/IPRL/TMRL/FRL 六维评分	技术文档、专利	六维评分
决策综合 Agent	综合评分，生成立项/投资报告	各 Agent 输出	综合评分、报告
监控预警 Agent	跟踪关键信号，触发“变相时刻”提醒	信号更新	预警、复盘建议
Agent 编排架构
技术文档中采用 LangGraph 构建有向图工作流：

[趋势侦察] → [需求挖掘] → [市场测算] → [竞争情报] → [技术评估] → [决策综合] → [监控预警]
     ↑                                                                          ↓
     └────────────────────────── 反馈循环 ──────────────────────────────────────┘

●每个 Agent 是一个节点，状态在图中传递。
●支持并行执行、条件分支、循环。
●每个 Agent 继承 BaseAgent，统一结构：检索上下文 → 构建 Prompt → 调用 LLM → 解析输出 → 更新状态。
Agent 工具调用
每个 Agent 可调用专用工具，例如：
●趋势侦察：search_policies、search_patents、search_news
●需求挖掘：cluster_pain_points、sentiment_analysis
●市场测算：tam_sam_som_calculator
●竞争情报：competitor_discovery、patent_analysis
●技术评估：trl_assessment、crl_assessment
●决策综合：scorecard_calculator、report_generator
●监控预警：rule_engine、anomaly_detection

三、原型中的体现
在原型设计文档中，也专门为 Agent 设计了交互：
●工作台：显示 Agent 运行状态、任务进度。
●需求探针：分析进度条显示“正在聚类痛点…”，对应需求挖掘 Agent 运行。
●趋势雷达：趋势卡片由趋势侦察 Agent 生成。
●赛道评分：决策综合 Agent 汇总各维度评分。
●决策报告：决策综合 Agent 生成报告草稿。
●监控复盘：监控预警 Agent 触发预警，复盘后校准评分模型。

四、总结
赛道罗盘不是简单调用一次大模型，而是：
●大模型作为认知引擎，负责理解、推理、生成；
●多智能体作为协作系统，分工完成趋势、需求、市场、竞争、技术、决策、监控；
●RAG + 知识图谱 + 向量库提供证据支撑；
●LangGraph 编排工作流，让 Agent 之间传递状态、循环反馈；
●人机协同：AI 出初稿，专家校准，评分模型持续迭代。
所以，这个产品从底层到交互都完整设计了大模型和智能体，其核心定位就是“AI 驱动的科技公司商机发现与赛道选择决策系统”。
