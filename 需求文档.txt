产品设计：赛道罗盘（TrackCompass）
一句话定位：一个 AI 驱动的科技公司商机发现与赛道选择决策系统，把“凭感觉选方向”变成“信号扫描 → 机会生成 → 需求验证 → 技术匹配 → 决策报告 → 持续监控”的可追溯流水线。

一、目标用户与核心痛点
用户	痛点
科技公司创始人/CEO	技术强但不知道往哪个市场打，怕选错赛道浪费窗口期
战略部/创新部	信息分散在报告、专利、融资、招聘、社媒里，缺少系统化筛选工具
产品负责人	有技术方案，但无法量化验证市场需求和竞争壁垒
产业集团投资部	需要从集团能力出发筛选协同赛道，而非通用投资分析
核心价值：不是资讯聚合，而是决策操作系统——结合公司自身能力，输出可验证、可复盘、可监控的赛道选择建议。

二、产品架构：四层 + 七 Agent
1. 信号层（数据采集）
●宏观政策、技术论文/专利、融资事件、招聘 JD、招标信息、应用商店评论、社媒投诉、财报、供应链数据。
●支持 API、爬虫、人工上传、第三方数据源接入。
2. 认知层（AI 分析）
●知识图谱：技术—产品—公司—赛道—政策—资本关系。
●向量库 + RAG：让 LLM 基于证据回答，减少幻觉。
●评分模型：赛道评分卡、需求强度、技术成熟度、大厂威胁。
3. 决策层（工作流）
●能力画像 → 机会图谱 → 赛道评分 → 验证实验 → 决策报告。
●每个结论带证据链，可下钻到原始数据。
4. 行动层（监控与复盘）
●信号预警、假设看板、实验追踪、决策复盘库。
7 个 AI Agent
Agent	职责
趋势侦察 Agent	每日扫描 PESTEL、技术拐点、政策红利
需求挖掘 Agent	聚类社媒/评论/招标/招聘中的痛点，输出需求强度
市场测算 Agent	自下而上+自上而下测算 TAM/SAM/SOM
竞争情报 Agent	竞品动态、大厂威胁、替代方案、供应链卡点
技术评估 Agent	TRL/CRL/BRL/IPRL/TMRL/FRL 六维评分
决策综合 Agent	综合评分，生成立项/投资报告
监控预警 Agent	跟踪关键信号，触发“变相时刻”提醒

三、核心功能模块
1. 公司能力画像
输入：技术栈、专利、人才结构、资金、渠道、客户资源、供应链。
输出：能力向量 + 可进入赛道边界。
关键：赛道推荐必须与公司能力匹配，而非单纯追风口。
2. 趋势雷达
●PESTEL 宏观扫描 + 技术成熟度曲线 + 资本热度 + 政策文件。
●输出：候选技术方向列表，标注“顺风/逆风”。
3. 机会图谱
●赛道节点、上下游、玩家、专利、融资、招聘热度。
●可视化：赛道地图 + 竞争格局 + 空白点。
4. 需求探针
●接入社媒、评论、论坛、招标、招聘 JD。
●LLM 聚类痛点，输出需求强度、付费意愿、客户就绪水平（CRL）。
●自动生成访谈提纲、问卷、落地页测试方案。
5. 赛道评分卡
可配置权重，默认维度：
维度	权重示例
市场空间	20%
需求真实性	20%
技术成熟度	15%
竞争壁垒	15%
商业模式	10%
时机	10%
内部匹配度	10%
输出：机会评分、雷达图、风险预警、排序列表。
6. 验证实验管理
●假设 → 实验 → 指标 → 结论。
●支持落地页、预售、POC、客户访谈、渠道测试。
●自动追踪实验数据，更新赛道评分。
7. 决策报告生成
●一键生成立项报告/投资备忘录，含证据链、假设清单、里程碑、风险。
●可导出 PPT/Word/Notion。
8. 监控与复盘
●关键信号变化时预警：政策、融资、大厂入场、技术突破。
●记录决策依据，事后复盘，校准评分模型。

四、典型工作流
1.建立能力画像：公司输入技术、人才、资金、渠道。
2.设定搜索边界：行业、技术、地域、阶段。
3.系统扫描：Agent 生成候选机会池。
4.初筛评分：赛道评分卡 + 风险预警。
5.深挖验证：需求探针 + 技术评估 + 竞争情报。
6.决策报告：综合评分 + 立项建议。
7.持续监控：信号更新，触发复盘。

五、MVP 设计（3 个月）
目标：验证“AI 能否帮科技公司更快筛出可验证赛道”。
●聚焦垂直领域：如 AI+制造、AI+医疗、新能源科技。
●接入 5–8 个数据源：政策、专利、融资、招聘、社媒、招标。
●实现 4 个核心模块：趋势雷达、赛道评分卡、需求探针、报告生成。
●人机结合：AI 出初稿，专家校准。
●技术栈：LLM + RAG + 向量库 + 知识图谱 + BI 仪表盘。
●成功指标：机会发现数量、验证周期缩短比例、报告采纳率、付费转化。

六、商业模式
版本	内容	定价
免费版	基础趋势报告、有限赛道扫描	引流
专业版	赛道评分、需求探针、报告生成	SaaS 订阅
企业版	私有化部署、定制数据源、专家服务	年费+服务费
API/数据	赛道评分、需求强度 API	按量

七、差异化与护城河
●不是资讯聚合：是决策流水线，输出可执行建议。
●结合内部能力：赛道推荐与公司技术、人才、渠道匹配。
●证据链可追溯：每个结论可下钻到原始数据。
●持续监控：不是一次性报告，而是动态预警。
●人机协同：专家校准沉淀为评分模型，越用越准。

八、风险与应对
风险	应对
数据版权/隐私	合规采集，企业数据本地化
模型幻觉	RAG+引用来源，人工复核
用户不愿输入内部数据	隐私保护、私有化部署
专家依赖	知识沉淀，评分模型自动化

总结：赛道罗盘的本质是科技公司的赛道决策操作系统。它把 PESTEL、TAM/SAM/SOM、TRL/CRL、BXT、赛道评分卡等方法论固化为工作流，用 AI Agent 完成信号扫描、需求验证、竞争分析和报告生成，最终帮科技公司找到“技术能力、市场需求、商业模式”的交集。
